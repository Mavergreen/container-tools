**New version numbers.** Container Tools is now numbered by date, `YYYYMMDD.N`, instead of
`20260727-mavericks.N`. The date moves whenever Container Tools itself changes, and `.N` counts
releases that only update the bundled components (docker, Compose, Machine, lazydocker, boot2docker,
Go). Your Mac sees this release as newer than `20260727-mavericks.37` and updates as usual.

Otherwise this is the same Container Tools as `20260727-mavericks.37`: the same component versions
and no change in how it behaves. Behind the scenes, the build now installs its Go toolchain where
each Go release says it lives, and its downloads retry on network errors.
