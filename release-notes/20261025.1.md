**Docker tells you when your Mac's disk is full.** When your Mac runs out of disk space, VMware
pauses the Docker VM, and Container Tools used to say nothing (or "Updating VM image…" forever).
Now the menu says "Docker: Paused (Mac disk full)", the icon gets a badge, and you get a
notification. Free some space and Docker carries on by itself.

**Docker won't start into a full disk.** The Docker VM needs free space on your Mac about the size
of its memory each time it starts. If there isn't enough, Start Docker and Update VM Image now say
how much space is needed instead of starting and getting stuck. A refused Update VM Image leaves
Docker running.

**Long VM image updates are left alone.** An Update VM Image that took more than ten minutes used
to have Docker started again underneath it. Now it is left to finish.
